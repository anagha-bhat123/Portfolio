# Anagha Bhat Portfolio

A personal portfolio website for **Anagha Bhat**, a full stack developer and MCA student. The site showcases skills, projects, academics, achievements, and contact details in a modern responsive layout.

## Overview

- Built with **HTML**, **CSS**, and **JavaScript**.
- Responsive navigation with mobile menu support.
- Animated hero section with dynamic text typing.
- Interactive particle background and scroll reveal effects.
- Sections for About, Skills, Projects, Academics, Achievements, and Contact.

## Files

- `index.html` - Main portfolio page markup.
- `style.css` - Custom styles and responsive layout.
- `script.js` - Navbar behavior, typewriter animation, particle background, and reveal effects.
- `Anagha dp.jpeg` - Profile image displayed in the hero section.

## Features

- Sticky navigation bar with active section highlighting.
- Hamburger menu for small screens.
- Animated skill orbit and progress visuals.
- Smooth scrolling between sections.
- Social links to LinkedIn, GitHub, and email.

## Run Locally

1. Clone or download the repository.
2. Open `index.html` in your browser.

> No build step is required. The website runs as a static site.

## Notes

- Update the `href` values and profile links in `index.html` if you want to connect to different social profiles.
- Replace the profile image `Anagha dp.jpeg` with your own image if needed.
